# SSG Exercise (Eleventy)

Builds two portfolio pages, **Home** (`index.html`) and **About** (`about.html`), with a shared footer in `_includes/footer.njk`.

## Commands

Run these from inside `ssg-exercise/`.

Install dependencies:

```bash
npm install
```

Build the site into `_site/`:

```bash
npm run build
```

Preview locally (builds, serves, and rebuilds on changes):

```bash
npm start
```

Then open:

- Home: http://localhost:8080/
- About: http://localhost:8080/about.html
